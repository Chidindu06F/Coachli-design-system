# Coachli Design System

The design system for the Coachli dashboard: a Figma library and a React component library built from the same design tokens. Figma is the source of truth; the code mirrors it.

## Install

The packages are on GitHub Packages, which needs a one-time setup (a token and an `.npmrc` file). The steps are in the [README](https://github.com/Chidindu06F/Coachli-design-system#install). Then:

```bash
npm install @chidindu06f/coachli-react @chidindu06f/coachli-tokens
```

Load the tokens and the component styles once, at the top of your app (for example `main.tsx` or your root layout):

```tsx
import '@chidindu06f/coachli-tokens/css';      // colours, spacing, type and radius as CSS variables
import '@chidindu06f/coachli-react/styles.css'; // styles for every component
```

The components use the **Inter** font. Load it yourself, for example with Fontsource:

```bash
npm install @fontsource/inter
```

```tsx
import '@fontsource/inter/400.css';
import '@fontsource/inter/600.css';
import '@fontsource/inter/700.css';
```

Then use the components:

```tsx
import { Button } from '@chidindu06f/coachli-react';

export function Save() {
  return <Button>Save changes</Button>;
}
```

To change how one component looks on one screen, see **Customising** in the sidebar.

## Light and dark mode

Set `data-theme` on the `<html>` element:

<table>
  <thead>
    <tr><th>Value</th><th>Result</th></tr>
  </thead>
  <tbody>
    <tr><td><em>(none)</em> or <code>light</code></td><td>Light mode</td></tr>
    <tr><td><code>dark</code></td><td>Dark mode</td></tr>
    <tr><td><code>system</code></td><td>Follows the user's operating-system setting</td></tr>
  </tbody>
</table>

```html
<html data-theme="system">
```

## Using tokens directly

Every token is a CSS variable prefixed with `--halo-` (the prefix comes from Halo, the open-source system this one is based on):

```css
.card {
  background: var(--halo-surface-primary);
  color: var(--halo-text-primary);
  border: 1px solid var(--halo-border-secondary);
  border-radius: var(--halo-radius-sm);
  padding: var(--halo-spacing-md);
}
```

See **Foundations** in the sidebar for every token, and use the theme switcher in the toolbar to preview light and dark mode.
