# Writing copy

Coachli copy is short, plain and easy to scan. Say what the person needs to know in one line, then stop.

## Voice

- **Plain words.** Write the way you would say it to a coach sitting next to you. "Get paid" not "Receive remittance".
- **One idea per line.** Helper text, descriptions and empty states fit in **two lines at most**, usually one.
- **Talk to the person.** "Your payout is on its way", not "The payout has been initiated".
- **Active and direct.** "We'll email your customers", not "Customers will be notified by email".
- **No filler.** Drop "please", "simply", "just", "successfully", "in order to".
- **Calm.** No exclamation marks, no jokes in errors, no ALL CAPS.
- **No helper lines that repeat the label.** If the label says it, leave the hint out.

## Sentence case

All Coachli text is written in **sentence case**, never title case or all caps.

- **Capitalise only the first word** of a title, label, button, phrase or sentence, **and proper nouns** (Coachli, Google Meet, Zoom, WhatsApp, Paystack, Kemi).
- It applies to everything we write: page and section titles, buttons, tabs, menu items, field labels, badges, toasts, empty states, emails.
- Feature names are not proper nouns: "Create a one-off session", "Your live events", "Sales and insights". They take a capital only when they start the line.
- **Text people type themselves is left as they wrote it.** Offering names, event titles, bios and messages keep the coach's or customer's own capitals.
- **No exclamation marks.**

| Do | Don't |
| --- | --- |
| Sales and insights | Sales And Insights |
| Create a one-off session | Create a One-Off Session |
| Connect Google Meet | Connect google meet |
| Save as draft | SAVE AS DRAFT |
| Event rescheduled | Event rescheduled! |

## By element

| Element | Rule | Example |
| --- | --- | --- |
| Page title | The thing, 1–3 words | Invoices, Live events, Payout |
| Flow title | The exact action and kind | Create a one-off session, Edit invoice |
| Button | A verb, 1–3 words, says what happens | Publish, Reschedule, Save as draft, Register now |
| Menu item | A verb or the thing, no ending punctuation | Edit, Duplicate, Copy link, Sales and insights |
| Field label | A noun, no colon | Event name, Email, Event duration |
| Placeholder | A sample answer starting with "e.g." | e.g. Career clarity session |
| Helper text | Only when needed, one line | Customers see this on your profile page. |
| Error | The problem, then the fix if it isn't obvious. Ends with a full stop. No examples | Enter a valid link. Upload failed. Check your connection and retry. |
| Toast | What happened, past tense, title only | Link copied, Event rescheduled, Bug report sent |
| Empty state | Title says what's missing; one line says why it helps; one button | No invoices yet / Send your first invoice and get paid faster. / Create invoice |
| Confirm modal | Title asks the question; body says what happens; button repeats the verb | Delete this discount? / Customers can no longer use this code. / Delete |
| Alert | One line about this page | Your bank account needs verifying before your next payout. |
| Announcement bar | Event name and date only, 60 characters at most | Coachli Creators Summit · Thu 26 Nov |
| Greeting | Good morning / afternoon / evening, first name | Good morning, John |

## Product words

| Use | Don't use |
| --- | --- |
| One-off session, Session bundle | 1:1 session (for the single kind) |
| Live event | Webinar, class |
| Digital product, Service, Subscription | Item, listing |
| Customer | Client, buyer, user |
| Coach | Creator, host, seller |
| Payout | Withdrawal (as a page name) |
| Plural in menus that list kinds: One-off sessions, Live events | Singular |

## Names and sample data

- Sample people are **John Doe** and **johndoe@email.com** (then Kemi Lawal, Ada Obi and other neutral names). Never a real person's name.
- Sample data is believable: real-looking prices, dates and titles, never "Lorem ipsum" or "Test".
